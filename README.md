# EarthPulse

**EarthPulse** is an interactive planetary intelligence platform that brings Earth-system data into one place. Explore earthquakes, weather, air quality, solar activity and other planetary signals through maps, timelines, 3D visualization and source-aware explanations.

**Live:** https://earthpulse1.vercel.app/

## What EarthPulse includes

- 🌎 Interactive 3D Earth exploration
- 🌐 Planet Pulse planetary intelligence views
- 🌎 Earthquake and seismic-event exploration
- ☀️ Space-weather context
- 💨 Air-quality and atmospheric data views
- 📊 Analytics and Earth-data workspaces
- 🧭 Mission Control exploration
- 🤖 AI-assisted planetary explanations
- 🔎 Source, freshness and observed/derived data labeling

## Data philosophy

EarthPulse is designed to distinguish **observed data**, **derived calculations**, **analytical interpretation** and **demonstration UI**. When a connected source is unavailable, the interface should report the gap rather than fabricate a measurement.
