How does EarthPulse track earthquakes?

EarthPulse is a source-aware planetary intelligence interface that organizes available seismic observations into one readable workflow. For earthquake tracking, it is designed to ingest public seismic feed data when connected, normalize event fields, and present time, location, magnitude, depth, status and provenance without treating simulations as live measurements.

OBSERVED DATALOCATION + MAGNITUDEPROVENANCE

What EarthPulse does

  • Normalizes seismic events into a consistent EarthPulse event structure.
  • Surfaces practical fields such as event time, latitude, longitude, magnitude, depth and source.
  • Keeps observed records distinct from derived scores and interactive demonstrations.
  • Provides a single exploration layer that can connect an earthquake to wider Earth-system context.
  • Shows unavailable data as unavailable instead of inventing a value.

How the workflow works

1. Ingest

Retrieve an available public seismic feed.

2. Normalize

Map provider-specific fields into EarthPulse's common event model.

3. Validate

Preserve source timestamps and status labels.

4. Visualize

Show events in lists, maps, timelines or the 3D globe.

Data trust

EarthPulse should treat the upstream source as the authority for the observation. Any derived EarthPulse score, grouping or visualization is an interpretation layer and should be labeled accordingly.
