EARTHPULSE / SYSTEM GUIDE

Everything in the app, explained.

EarthPulse is a web-based Earth intelligence and exploration experience. This guide explains what each part of the app does, what its visual layers mean, and where to go when you want to explore a particular capability.

01 · Home

The landing page is the entry point and gives a visual overview of the EarthPulse experience.

HERO

Earth + India focus

The hero presents the EarthPulse visual identity with an interactive India map, the project credit and hidden interaction.

EXPLORE

Explore Earth

Scrolls into the main feature area where the Planet Pulse, Earth Intelligence, Mission Mode, AI and Live Earth concepts are introduced.

OG DASHBOARD

Open the original dashboard

The dedicated button opens the preserved OG dashboard instead of embedding it into the normal landing-page scroll.

REVIEWS

Good Reviews · 4★+

Positive feedback stored by the browser can be displayed automatically in the landing-page review section.

02 · Analytics

The Analytics page provides access to the EarthPulse analytical workspace.

WORKSPACE

Earth intelligence dashboard

Analytics opens the dedicated workspace interface and connects it to the preserved EarthPulse dashboard experience.

SIGNALS

Multiple Earth domains

The app is organized around domains such as climate, weather, seismic activity, air quality, oceans, atmosphere and space weather.

Interpretation: the Analytics interface should be read together with the data-status labels. A visualization is not automatically a live measurement simply because it appears in the dashboard.

03 · Data Atlas

The Data page explains how EarthPulse distinguishes different kinds of information.

OBSERVED

Direct data

Information presented as an observation or source feed. The source context should be checked in the relevant module.

MODELED

Derived estimates

Indicators calculated from other information are estimates rather than direct measurements.

INFERRED

Analysis

Analytical interpretations are conceptually separate from the underlying observations.

DEMO

Demonstration layers

Interactive demonstration targets are explicitly labeled so they are not confused with real-time event reports.

04 · Planet Pulse

A dedicated 3D planetary exploration interface powered by the EarthPulse globe system.

3D EARTH

Rotate and inspect

Use the globe as the primary interface for planetary exploration. The experience supports interactive navigation and zooming.

LIVE EARTH

Immersive mode

The Live Earth concept turns the planet into the main visual interface for an immersive exploration experience.

RADAR

Event visualization

Highlighted markers and radar-style visuals provide an exploration layer for locating and inspecting targets.

OG

Original dashboard

The OG dashboard remains separately accessible from the landing page and is not forced into the normal page scroll.

05 · Mission Control

Missions add a game-like exploration layer on top of the planetary visualization.

01 / SELECT

Choose a mission

Select a target from the mission library or use the available random-target interaction.

02 / NAVIGATE

Move the globe

Rotate and zoom the planet to inspect the highlighted region.

03 / CONFIRM

Find the target

Select the correct interactive marker to complete the mission.

04 / REWARD

Receive XP

The mission interaction can award the displayed exploration XP.

06 · EarthPulse AI

The AI layer is intended to explain the Earth context being explored rather than replace the underlying data.

ASK

Ask questions

Users can ask for explanations about Earth context, metrics or events represented by the interface.

CONTEXT

Explain what you are viewing

The landing experience describes the AI as context-aware: questions can be framed around the EarthPulse view being explored.

Important: AI explanations are an interpretation layer. They should not be treated as an independent source of measurement, and the underlying data/source context remains important.

07 · Feedback

The feedback system lets visitors record product feedback and receive an immediate browser-side response.

FEEDBACK FORM

Different feedback genres

Visitors can submit bug reports, feature requests, data/source notes, design feedback or general comments with a 1–5 star rating.

AUTOMATED REPLY

Instant response

The current system chooses a response based on the feedback type, rating and message tone, then displays it immediately in the browser.

REVIEWS

4★+ review section

The feedback page has a Good Reviews section that filters positive ratings, while the landing page can surface those same locally stored reviews.

LOCAL STORAGE

Current persistence model

The present feedback implementation stores submissions in the visitor's browser. It is not a shared server-side review database.

08 · Easter eggs

Small hidden interactions are part of the EarthPulse experience.

INDIA

India signal

Interact with the India region on the landing-page globe to trigger its hidden signal response.

LOGO

Logo sequence

The EarthPulse logo has a hidden multi-click interaction.

KEYBOARD

Signal sequence

A hidden keyboard sequence can unlock another EarthPulse message.

MISSION

Exploration layer

Some hidden interactions are designed around the same discovery and mission theme as the planetary explorer.

09 · How to read EarthPulse

The interface deliberately separates exploration, analysis and demonstration.

SOURCE FIRST

Check the context

When a module provides source or status information, use it before interpreting a visualization as a current observation.

NO BLURRING

Observed ≠ modeled ≠ demo

EarthPulse's Data Atlas explicitly distinguishes observed information, derived estimates, inferred analysis and demonstration layers.

EXPLORATION

Interactive does not mean live

Globe markers, missions and visual effects can be interactive without representing a live event. The labels provide that distinction.

FEEDBACK

Help improve the system

Use the Feedback page when something is unclear, broken or worth adding. The current system responds locally in the browser.
