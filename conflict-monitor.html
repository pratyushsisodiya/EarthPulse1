Conflict Monitor.

A neutral EarthPulse workspace for tracking active armed conflicts, reported fatalities, displacement and humanitarian impact. Figures are labelled by source and uncertainty instead of being presented as exact counts.

Data postureSOURCE-FIRST
Source first. Demo second. Conflict casualty figures can be incomplete, delayed or disputed. EarthPulse uses verified sources when available and falls back to clearly labelled synthetic demo data when they are unavailable.

Data provenance

Every future live metric should carry its dataset, retrieval date and source URL. The estimate engine uses a median of independent reported figures when enough comparable reports are available; it is an aggregation of reports, not an independently verified death toll. EarthPulse does not merge incompatible casualty estimates into a single number. UCDP exposes public endpoints including BattleDeaths and GED events; ACLED requires authenticated API access; humanitarian datasets can be discovered through HDX.

How EarthPulse should source this layer

The interface is intentionally designed around primary and specialist datasets. UCDP provides structured data on organized violence; ACLED provides event-level political violence data; UN humanitarian agencies publish situation reports and displacement information. Where sources disagree, EarthPulse should show the disagreement and the date rather than silently merging numbers.
